# 學習小站

小五到國三的英文、數學、自然、社會、國文練習：小遊戲、闖關、互動簡報和延伸閱讀。每個頁面都是靜態 HTML（朗讀音檔另放），不需要伺服器、資料庫或 API 金鑰。首頁可以依年級篩選（小五／國一／國二／國三／國文）。

網站：https://max104210803.github.io/english-games/
